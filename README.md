# Dungeon Crawler Carl — THE DESCENT
A full cinematic, horror‑comedy, broadcast‑style campaign framework for running a Dungeon Crawler Carl–inspired TTRPG. This repository contains everything needed to run the campaign known as **THE DESCENT**, including:

- Complete campaign storyline
- Fully written Floor 1, Floor 2, and Floor 3 Lockout packets
- GM workflows
- Encounter systems
- NPC dossiers
- Chaos tables
- Broadcast scripts
- Templates for future floors
- Example packets

This repo is designed for use with:
- Foundry VTT / Roll20
- Dungeon Alchemist / Inkarnate / Dungeondraft
- Crawler Companion
- Ginger Dragon RPG Companion

## 🚀 Quick Start

1. Read `/campaign/storyline.md`  
2. Read `/docs/00_campaign_vision.md`  
3. Run Session 0 using `/templates/session_template.md`  
4. Begin Floor 1 using `/campaign/floor_01_the_homecoming/overview.md`  
5. Use `/docs/` during play for reference  
6. Use `/templates/` to build new content
